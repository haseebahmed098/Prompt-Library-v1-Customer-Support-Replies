# Prompt-Library-v1-Customer-Support-Replies
Professional prompt engineers don't rewrite prompts from scratch every time — they build reusable "templates" with placeholders, the same way developers use functions instead of copy-pasting code. In this task, you'll design your own mini prompt library for a real use case (customer emails, social captions, or study notes — your choice) using a consistent template structure: Role + Context + Task + Format + Constraints.

* Choose one use case: customer support replies, social media captions, or study/exam notes
* Design a reusable prompt template with clearly labeled sections: Role, Context, Task, Format, Constraints
* Create at least 5 different prompts from that same template (just swapping the variables)
* Test all 5 in your AI tool of choice and save the outputs
* Package everything into a simple doc (Notion, Google Doc, or markdown file) as your "Prompt Library v1"
